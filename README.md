### Hi, I'm Kevin Pedroso 👋

I build **connected products end to end**: firmware, hardware, cloud and the app on top. I'm a developer at **[DevSkin](https://devskin.com)**, based in Campinas/SP, Brazil.

- **Apps & software:** iOS/Android apps in Flutter, web dashboards and the APIs behind them.
- **IoT, firmware to cloud:** ESP32 and LoRa devices with OTA, telemetry pipelines, MQTT, alerts.
- **Industrial automation:** machine retrofits, Modbus RTU/RS-485 and PLC integration, safety upgrades, plus the cloud-side automations that act on that data.
